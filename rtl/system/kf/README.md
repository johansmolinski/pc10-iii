# KF82xx chips

The Intel 8237/8253/8255/8259 equivalents by kitune-san (KFPC-XT project,
MIT licence, see each LICENSE), in the clock-enable versions of the MiSTer
PCXT core (https://github.com/MiSTer-devel/PCXT_MiSTer, rtl/KFPC-XT/HDL, commit
efce7775a2ed748cf2ee93ef22ceb7d1a05955c4). Copied unchanged except that the
`*_inst.sv` instantiation templates were left out. Changes made here get a
`pc10-iii` comment.
